# AnalyX

AnalyX is a sentiment-analysis web app. Its browser UI is plain HTML, CSS, and JavaScript, and a FastAPI application provides the API and runs VADER and multilingual DistilBERT. It does not require Streamlit and can run on Python ASGI hosts or any host that supports Docker. Users can analyze direct text, import historical feedback, or submit a social-post or product-review link.

## Run locally

Use Python 3.10 or later:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app:app --reload
```

Open <http://localhost:8000>. The first analysis downloads the VADER lexicon and the DistilBERT model.

## Project layout

```text
app.py                 Deployment entry point (Vercel and Uvicorn)
analyx/
  api.py               FastAPI routes and request handling
  extractors.py        CSV, Excel, and PDF ingestion
  models.py            VADER and DistilBERT sentiment engine
  visualizations.py    Shared sentiment-rendering helpers
public/
  index.html           Browser app
  app.js
  styles.css
  assets/              Public brand assets
tests/                 Automated tests
```

The root `app.py` intentionally stays as a small wrapper so deployment platforms can discover the API consistently. Keep application code in the `analyx/` package, browser files in `public/`, and tests in `tests/`. Python virtual environments, secrets, and generated bytecode are excluded from version control.

## Link-based comments and reviews

The link workflow recognizes YouTube, Instagram, Facebook, TikTok, and Amazon URLs. YouTube is currently the only connected link provider. It uses the official YouTube Data API v3. Create a Google Cloud project, enable YouTube Data API v3, and create an API key with appropriate API restrictions. Configure the key as the `YOUTUBE_API_KEY` environment variable on the server; never put it in browser code or commit it to the repository.

For local PowerShell use:

```powershell
$env:YOUTUBE_API_KEY = "your-api-key"
uvicorn app:app --reload
```

For Docker, set the variable in the host's secret/environment-variable settings (or pass it locally with `docker run -e YOUTUBE_API_KEY ...`). For Vercel, add `YOUTUBE_API_KEY` in the project's Environment Variables settings and redeploy.

Link-based analysis is capped at 100 comments or reviews per link. YouTube reads publicly available top-level comments only; it does not include replies, private comments, or live monitoring. YouTube API quota and access restrictions apply. Instagram, Facebook, TikTok, and Amazon links are recognized but return a clear “integration not connected” response until their approved server-side integrations are configured. Each service has different permissions and limitations; a URL alone does not grant access to comments or reviews. AnalyX does not scrape pages or attempt to bypass access controls. Import an exported CSV or Excel file for sources that are not connected. File imports retain a separate 2,000-row analysis cap. Sentiment charts use DistilBERT's positive/neutral/negative labels, while VADER is shown as a comparison.

## Deploy with Docker

Build and run the included image locally:

```powershell
docker build -t analyx .
docker run --rm -p 8000:8000 analyx
```

For a Docker-compatible host, deploy this repository using its `Dockerfile`. The server listens on the host-provided `PORT` environment variable, falling back to port 8000. This works with container hosts such as Render, Railway, and Fly.io; configure the service to use the repository's Dockerfile and expose its assigned port.

The first analysis downloads the VADER lexicon and DistilBERT model. Allow outbound access to Hugging Face and enough memory and disk space for the model. Hosts with ephemeral filesystems may download the model again after a restart.

## Deploy to Vercel

Import this repository as a Vercel project and deploy with the default Python/FastAPI settings. Vercel serves `public/` through its CDN and runs the FastAPI app in `app.py`. The included `vercel.json` allows up to 300 seconds for analysis.

The app keeps its existing PyTorch/Transformers models, so check the resulting function bundle against Vercel's Python bundle limit (500 MB by default; larger functions are a Vercel beta feature). The model is downloaded when a function instance first analyzes text, so the first request can be slow and will require outbound access to Hugging Face. Functions are temporary; the model may need to be downloaded again on a cold start. Dataset uploads are limited to 4 MB, and batches are capped at 2,000 rows.

If Vercel cannot build the model dependencies within your account's limits, use the Docker deployment above or deploy the same app to another Python ASGI host. The frontend and API are served together by the app locally and in Docker; Vercel serves the static frontend through its CDN.
